## 📖 About

**Tulu** (ISO 639-3: `tcy`) is a South Dravidian language spoken by approximately **2.5 million people** in the Tulu Nadu coastal region of Karnataka and Kerala, India. Despite its rich oral and cultural tradition, it remains one of the most under-resourced languages in NLP and machine translation. **TuluBridge** changes that.

This project:
- Provides translation from Tulu ↔ English
- Is powered by a fine-tuned IndicBARTSS model using transfer learning from Kannada
- Exposes a public REST API any developer can integrate
- Offers a fast and modern web interface accessible to all users
